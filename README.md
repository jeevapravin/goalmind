# GoalMind

> AI-powered personal finance assistant that helps users save smarter, budget better, and achieve their financial goals.

## Overview

GoalMind is an intelligent financial management platform that combines budgeting, expense tracking, goal planning, and AI-powered insights into a single application.

Instead of simply recording transactions, GoalMind understands spending behavior, provides personalized recommendations, and helps users make better financial decisions.

---

## Features

- AI-powered financial assistant
- Expense & income tracking
- Smart transaction categorization
- Budget creation and monitoring
- Savings goal management
- Goal progress visualization
- Personalized financial insights

## Getting Started

### Clone the repository

```bash
git clone https://github.com/tonypanda7/goalmind.git
```

### Install dependencies

```bash
npm install
```

### Configure environment

Create a `.env` file and configure the required environment variables.

Example:

```env
DATABASE_URL=
JWT_SECRET=
OPENAI_API_KEY=
```

### Run the project

```bash
npm run dev
```
